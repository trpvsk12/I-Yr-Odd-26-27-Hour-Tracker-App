FACULTY TRACKER - ANDROID APK PROJECT

This project contains the complete First Year Faculty Tracker web app inside an Android WebView.
It includes the complete timetable data already supplied for the app.

FASTEST WAY TO GET THE APK:
1. Create a GitHub repository, e.g. faculty-tracker-android.
2. Upload ALL files/folders from this project to the repository root.
3. Go to the repository's Actions tab.
4. Select "Build Faculty Tracker APK".
5. Click "Run workflow".
6. When it finishes, open the workflow run and download the artifact named "Faculty-Tracker-APK".
7. Inside it is app-debug.apk.
8. Transfer the APK to your Android phone and install it.

NOTE:
The GitHub Action builds an installable debug APK. Android may show a warning because it is not published through Google Play.
For a Play Store release, the APK should be signed with a release key.
